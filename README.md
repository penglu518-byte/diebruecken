# DIE BRÜCKEN / 桥 2027 — 项目网页

中德建交 55 周年 · 中德文化与对话交流季 2027 的策划同步页面（中文 / 德文）。

## 如何更新内容

- 中文：`content/zh.js`
- 德文：`content/de.js`

两个文件结构一一对应，改一处时请同步另一处。提交并推送到 GitHub 后，Netlify 会自动重新发布。

这是对外展示的网站：只放已对外确认的内容，筹备进度、内部讨论和未确认事项不放在这里。
“2027 日程”中当前进行的节点会根据日期自动高亮，已过去的节点自动变淡。

## 本地预览

```
python3 -m http.server 8642
```

然后打开 http://localhost:8642/?lang=zh 或 ?lang=de。

工作稿阶段页面设置了 noindex（不被搜索引擎收录），正式公开前在 `index.html` 和 `netlify.toml` 中删除即可。
